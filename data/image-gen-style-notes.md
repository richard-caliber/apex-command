# Image Style Notes — War Room Project Cards

Date: 2026-05-06
Reference cards reviewed: caliber-card.jpg, gemsnap-card.jpg, parliament-card.jpg, storyquest-card.jpg, edgeauto-card.jpg

## Format
- Aspect ratio: **1:1 square**
- Resolution: **~1024x1024**
- File format: JPG (PNG also acceptable, .svg used in one case)
- File size: ~15KB-120KB

## Visual language
- **Background:** Deep black / near-black, often with faint particles or distant glow
- **Subject:** Single dominant icon or symbol centered (or off-centered with intent)
- **Style:** Illustrative / painterly with strong rim lighting and luminescent glow — NOT photographic, NOT flat vector
- **Mood:** Cinematic, atmospheric, slightly mysterious
- **Color treatment:** Each card uses a **single dominant accent colour** against the black:
  - Caliber: cyan/blue (DNA helix, molecule diagrams) — biotech/science
  - GemSnap: purple (amethyst crystal cluster) — gem/value
  - Parliament: red + blue (vertical light bars over silhouetted Big Ben) — UK politics duality
  - StoryQuest: warm gold (open storybook with dragon, castle, rocket) — magical/imagination
  - Edge Auto: cyan + amber (robotic arm + circuit traces + gears) — automation
- **Lighting:** Soft inner glow on the subject, vignette/falloff at edges
- **Detail level:** Iconic / symbolic, not literal — captures the project's essence in one image

## Composition rules to apply
1. Black background, no clutter
2. One central symbolic subject per card
3. Choose ONE dominant accent colour that maps to the project's domain
4. Painterly/illustrative — like a fantasy book illustration, not a stock photo
5. Soft glow / inner luminescence to the subject
6. No text, no logos, no UI elements
